# 🐞 Intelligent Software Defect Tracking System with Resolution Assistance

An interactive, AI-assisted defect analytics and priority prediction dashboard built with Python and Streamlit. This platform helps software development teams track defect lifecycles, monitor sprint performance, and identify high-risk modules.

## 🚀 Features
*   **Executive Analytics:** View Defect Tracking Funnels and Monthly Defect Trends.
*   **Quality & Performance:** Analyze resolution times by severity and priority using advanced heatmaps and treemaps.
*   **Team Workload:** Track assignee workload and SLA compliance.
*   **Interactive Filters:** Filter your entire dataset by Module, Sprint, and Severity.

## 🛠️ Tech Stack
*   **Python** (Core Logic)
*   **Streamlit** (Web Framework & UI)
*   **Pandas** (Data Manipulation)
*   **Plotly** (Interactive Visualizations)
