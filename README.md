# 🐞 Intelligent Software Defect Tracking & AI Prediction System

## 📌 About the Project
This is an interactive, AI-powered software defect tracking dashboard built with Python and Streamlit. It helps software development teams monitor bug lifecycles, analyze module vulnerabilities, and uses Machine Learning to predict bug priorities on the fly.

### 🚀 Key Features
* **Executive Dashboard:** Dynamic KPIs and interactive charts tracking bug severity, team workloads, and overall project health.
* **AI Priority Predictor:** Uses a **Random Forest Machine Learning model** to automatically predict a new bug's priority based on its severity and affected module.
* **Interactive Visualizations:** Beautiful, responsive charts that help teams easily identify software bottlenecks.

## 🛠️ Tech Stack
* **Python:** Core backend logic
* **Streamlit:** Web framework and UI
* **Scikit-Learn:** Machine Learning (Random Forest Classifier & Label Encoder)
* **Pandas & Plotly:** Data processing and interactive visualizations
